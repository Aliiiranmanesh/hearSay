Mechanisms: Iran's filtering infrastructure, administered primarily through the Supreme Council of Cyberspace and implemented through a small number of state-controlled internet exchange points through which all Iranian internet traffic passes, uses deep packet inspection technology that identifies encrypted traffic patterns characteristic of VPN protocols and throttles or blocks them at the infrastructure level rather than at the application level. ### 1. If you are using Google Colab (Most Common)
Colab will disconnect you if it detects "idleness." You can trick it into thinking you are still there by using a tiny bit of JavaScript in your browser.

1.  Press `Ctrl + Shift + I` (Windows) or `Cmd + Option + I` (Mac) to open the **Developer Console**.
2.  Paste this code into the console and press Enter:

```javascript
function KeepAlive() {
    console.log("Keeping alive...");
    document.querySelector("colab-connect-button").click();
}
setInterval(KeepAlive, 60000);
```
*This will "click" the connection button every 60 seconds to prevent the idle timeout.*

---

### 2. If you are using SSH (Terminal/Command Line)
If your terminal closes every time you stop typing for 5 minutes, you need to turn on "KeepAlive."

*   **On your local computer (Mac/Linux):**
    Open your SSH config file: `nano ~/.ssh/config`
    And add these lines:
    ```text
    Host *
        ServerAliveInterval 60
        ServerAliveCountMax 10
    ```
*   **On Windows (PuTTY):**
    Go to **Connection** -> **Seconds between keepalives** and set it to `60`.

---

### 3. Use "Tmux" or "Screen" (Essential for Servers)
If you are running a script and your computer turns off (or your internet drops), the script usually dies. **Tmux** keeps the session alive on the server even if you disconnect.

1.  Type `tmux` in your terminal.
2.  Run your script/code inside that window.
3.  If you get disconnected, just log back in and type `tmux attach`. Your code will still be running!
