## 1. Quick‑Fix Software Settings (Free)

| Platform | What to Change | Where to Find It |
|----------|----------------|------------------|
| **Windows 10/11** | Disable sleep, hibernate, and screen timeout | **Settings → System → Power & sleep** → set *Screen* and *Sleep* to **Never**. <br>For deeper control: **Control Panel → Power Options → Change plan settings → Change advanced power settings** → set *Sleep* → *Sleep after* = 0, *Hibernate after* = Never, *Turn off hard disk* = Never. |
| **macOS** | Prevent display and system sleep | **System Settings → Battery → Power Adapter** → turn on *Prevent computer from sleeping automatically when the display is off* and *Enable Power Nap* off. <br>Or use the terminal: `caffeinate -i -t 86400` (keeps the Mac awake for 24 h). |
| **Linux (most distros)** | Disable suspend/hibernate | Edit `/etc/systemd/logind.conf` → set `HandleLidSwitch=ignore`, `IdleAction=ignore`. <br>Or run: `sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target`. <br>For desktop environments: *Settings → Power* → turn off “Suspend when inactive”. |
| **Raspberry Pi / headless Linux** | Keep CPU awake | Add `dtoverlay=disable-wifi` (if Wi‑Fi is causing power‑save) or `disable_splash=1` in `/boot/config.txt`. <br>Use a watchdog: `sudo apt install watchdog && sudo systemctl enable watchdog`. |
| **Android** | Keep screen on / prevent Doze | **Settings → Display → Sleep** → set to longest time, or enable *Stay awake* in **Developer options** (keeps device on while charging). |
| **iOS** | Prevent auto‑lock | **Settings → Display & Brightness → Auto‑Lock** → set to **Never** (requires device to stay plugged in). |

### One‑liner “keep‑alive” commands

- **Windows:** `powercfg -change -standby-timeout-ac 0` (disables AC sleep).  
- **macOS:** `caffeinate -d -i -m -s` (keeps display, system, and network awake).  
- **Linux:** `while true; do sleep 300; echo "still alive"; done &` (a harmless keep‑alive loop).  

You can drop these into a startup script so they run automatically after a reboot.

## 3. Tweak the Device’s BIOS/UEFI (Free, but a little time)

Many computers, especially laptops and small servers, have built‑in power‑saving options that override the OS:

1. **Enter BIOS/UEFI** (usually `Del`, `F2`, or `Esc` at power‑on).  
2. Look for **Power Management** or **Advanced** tabs.  
3. Disable:
   - *Sleep Mode* / *S3 State*  
   - *Intel Rapid Start* / *AMD Deep Sleep*  
   - *Wake‑on‑LAN* (if you want the device to stay on, you can keep it enabled for remote wake‑ups).  
4. Save & exit.

*Result:* The hardware won’t force a shutdown even if the OS tries to sleep.

## 4. “Never‑Sleep” Scripts for Specific Use‑Cases

### a. **Keeping a Raspberry Pi always on (no extra hardware)**

```bash
# 1. Disable screen blanking (if you have a monitor)
sudo nano /etc/rc.local
# Add before "exit 0":
xset s off
xset -dpms
xset s noblank

# 2. Prevent the Pi from entering "power save" on Wi‑Fi
sudo nano /etc/modprobe.d/8192cu.conf
# Add:
options 8192cu rtw_power_mgnt=0 rtw_wifi_power_save=0

# 3. Enable watchdog (already cheap)
sudo apt-get install watchdog
sudo systemctl enable watchdog
sudo systemctl start watchdog
```

### b. **Windows “Never Sleep” batch file**

Create `keepawake.bat`:

```bat
@echo off
:: Disable sleep & hibernate
powercfg -change -standby-timeout-ac 0
powercfg -change -monitor-timeout-ac 0
powercfg -change -hibernate-timeout-ac 0
:: Keep console open
echo Device will stay awake. Press Ctrl+C to stop.
:loop
timeout /t 300 >nul
goto loop
```

Run it as **Administrator** once after each reboot.

### c. **macOS “caffeinate” launch agent**

1. Open `~/Library/LaunchAgents/com.user.keepawake.plist`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
 "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
  <dict>
    <key>Label</key><string>com.user.keepawake</string>
    <key>ProgramArguments</key>
    <array>
      <string>/usr/bin/caffeinate</string>
      <string>-d</string>   <!-- keep display awake -->
      <string>-i</string>   <!-- prevent idle sleep -->
    </array>
    <key>RunAtLoad</key><true/>
    <key>KeepAlive</key><true/>
  </dict>
</plist>
```

2. Load it: `launchctl load ~/Library/LaunchAgents/com.user.keepawake.plist`

Now the Mac will stay awake across reboots without any extra cost.

## 6. If You’re Still Hitting a Wall…

| Symptom | Quick Diagnosis | Free Fix |
|---------|----------------|----------|
| **Device powers off after X minutes of inactivity** | Likely OS power plan. | Apply the OS settings above. |
| **Device shuts down when a USB device is attached** | Some boards treat USB as a power‑off trigger. | Disable USB selective suspend (Windows: *Power Options → USB settings*). |
| **After a power outage it never boots again** | BIOS “Restore on AC/Power Loss” set to *Stay Off*. | Enter BIOS and set *Restore on AC Power Loss* → *Power On*. |
| **It still sleeps when the lid closes** | Laptop lid actions not overridden. | In Windows: *Power Options → Choose what closing the lid does* → set to *Do nothing*. In Linux: `sudo nano /etc/systemd/logind.conf` → `HandleLidSwitch=ignore`. |
