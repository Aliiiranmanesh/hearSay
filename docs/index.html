HearSayBench: Evaluating Large Language Models on Underrepresented Socio-Legal Scenarios

Applying the Capabilities Approach framework (Sen, 1999; Nussbaum, 2011) to test whether LLMs maintain accurate world models for individuals whose real-world struggles and conversion impediments are structurally missing from web training corpora.

Quick Start & Pipeline Usage

Load HearSayBench directly in Python or run the evaluation pipeline from GitHub.

Load via Hugging Face Datasets 
from datasets import load_dataset

# Load HearSayBench dataset (400 socio-legal scenarios)
dataset = load_dataset("aliIranmanesh/HearSayBench")

# Inspect the first scenario
first_entry = dataset["train"][0]
print(f"Scenario: {first_entry['scenario']}")
print(f"Prompt: {first_entry['prompt']}")
Run Evaluation Pipeline 
# Clone repository & install dependencies
git clone https://github.com/Aliiiranmanesh/hearSay.git
cd hearSay
pip install -r requirements.txt

# Run pipeline with dynamic HF loading
python run_pipeline.py aliIranmanesh/HearSayBench --model gemini-3.5-flash
